# Что нового

Раздел `## X.Y.Z` становится текстом выпуска на GitHub (его берёт `.github/workflows/release.yml`).

## 1.3.1

- База модов обновляется сама: при запуске программа проверяет, изменилась ли выгрузка RePoE (после патча
  игры), и скачивает свежую — вместе с русскими данными, если они уже были. Удалять папку `data` больше не нужно.
  Нет интернета — работает на сохранённой базе.
  The mod database updates itself after game patches — no need to delete the `data` folder.

## 1.3.0

- Русский клиент игры: Ctrl+Alt+C, названия баз и моды на русском, распознавание подсказки (Windows OCR ru-RU).
  Язык клиента определяется сам по скопированному предмету; русские данные докачиваются при первом
  русском предмете. Нет русского пакета распознавания — программа предложит установить.
  Russian game client support (item copy, mods, OCR) — detected automatically.
- Программа одним файлом: PoECraftGuard.exe в выпуске (Python не нужен), обновляется сама.
  Single-file PoECraftGuard.exe in the release, no Python needed, self-updating.
- После обновления — кнопка «Перезапустить».

## 1.2.0

- Английский интерфейс / English interface: «⚙ Настройки» → «Общие» → «Язык» (Russian / English).
  Язык меняется сразу, выбранные моды и фильтры сохраняются. При первом запуске язык берётся из Windows.
- Окно настроек как в Awakened PoE Trade: разделы слева («Горячие клавиши», «Общие», «Охрана»,
  «О программе»), внизу «Сохранить» и «Отмена» (отменяет и переназначенные клавиши).
- README на английском — README.en.md.

## 1.1.0

- Обновления: в «⚙ Настройки» → «О программе» — версия, «Что нового», «Сообщить об ошибке»,
  проверка обновлений. Автообновление (по умолчанию включено): проверка при запуске и раз в 6 часов,
  новая версия скачивается сама, работает после перезапуска. `data/` и `config.json` не трогаются,
  прежние файлы — в `backup/`.
- Кнопка «⟳ Новая база» — сменить предмет (Ctrl+Alt+C на новом предмете, затем кнопка или F7).
- Ошибка импорта базы видна на плашке «База», а не пропадает сразу.
